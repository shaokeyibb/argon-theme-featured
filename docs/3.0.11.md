# 3.0.11：移动端安全区适配

修复异形屏上滚动正文出现在状态栏背景中的问题，并避免为顶部背景额外增加色带或把 Header 和正文向下推移。

- 使用 `viewport-fit=cover` 和浏览器提供的四边安全区尺寸，适配不同设备及横竖屏切换，不依赖机型识别或固定状态栏高度。
- iOS 导航栏使用统一的实色背景，并移除导航栏自身的背景模糊，由导航本身参与 Safari 顶部取色。独立顶部背景严格限制在实际安全区内，安全区为零时不绘制额外色带。
- 补齐移动菜单、侧栏、搜索弹窗、浮动按钮、底部设置面板和全屏 Banner 的安全间距，并同步调整目录跟随、滚动定位与阅读进度。
- 保留其他平台原有的顶部透明导航和滚动模糊效果，以及无 JavaScript 时的可读导航背景。

新增零安全区下无额外色带及布局位移的回归，并覆盖明暗模式、滚动、横竖屏切换、菜单、导航隐藏、隐藏 Banner 和无 JavaScript 场景。Chromium、Firefox 和 WebKit 共 45 项导航与布局回归通过；最终方案已由用户在部署预览中确认。

WordPress / PHP 最低要求保持 6.6 / 8.2。升级时同步完整构建资源，并清理页面、静态资源及 CDN 缓存。
