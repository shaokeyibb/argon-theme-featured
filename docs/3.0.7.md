# 3.0.7：HTML 文章响应式高度与移动端宽度

修复 HTML 文章在桌面和手机宽度之间切换后高度不准确、出现内部滚动条或停留在固定高度的问题。

- 移除主栏跨断点的宽度动画，避免文档被短暂挤窄而产生异常高度。
- 自动测高保留最后一次布局消息，计入正文底部边距，并在 iframe 实际尺寸变化后重新测量。短暂超过高度上限的内容收起或恢复布局后，可以继续自动调整高度。
- 自动高度模式由外层页面滚动，避免 WebKit 内部滚动条改变文字换行、使高度反复振荡。固定高度、视口模式和禁用脚本的文档仍保留内部滚动。
- 屏幕宽度不超过 600px 时，HTML 正文填满文章卡片，保留文档自身的内边距；标题、摘要和文本阅读区域继续保留阅读边距。兼容单栏和多栏主题布局。
- AI 摘要的 Android 图标替换为现有 Font Awesome 图库中的星光魔杖图标，无需新增图标依赖。

新增 Chromium、Firefox、WebKit 回归测试，覆盖双向缩放、长文章、展开收起、超高内容恢复及视口高度反馈循环。WordPress 和 PHP 最低版本保持 6.6 / 8.2。升级后请清理页面、静态资源和 CDN 缓存。
