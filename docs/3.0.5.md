# 3.0.5：首屏、资源与现有外观规范化

- 修复原生页面切换时 Header 先显示主题色再变透明的问题；首次绘制即使用正确状态，隐藏 Banner 和无 JavaScript 时保留有色导航。
- 修复后退/前进时卡片缩放入场动画干扰浏览器滚动恢复的问题；普通导航继续保留入场动画。
- 复用 Argon 原有 12 种配色，通过 WordPress `theme.json` / Global Styles 统一前台与编辑器中的主色、字体和相关外观变量，没有新增整套外观预设。
- 按官方 Sass 组件精简 Bootstrap，前台基础 CSS 原始大小减少 8.1%，gzip 减少 6.3%。前台和编辑器共享完整 Font Awesome 样式及字体，保留旧图标名称和 v4 兼容映射。
- 修复颜色选择器的小写 HEX 解析、ES module 未声明变量和灰度辅助函数递归问题，并在首帧恢复读者字体偏好。
- 增加资源体积预算、原生区块与阅读偏好测试、Chromium/Firefox/WebKit 回归，以及桌面/手机、日间/夜间截图基线。

WordPress 最低版本仍为 6.6，PHP 最低版本仍为 8.2。升级时应完整替换主题 PHP 和构建资源，并清理站点页面缓存。

本轮验证包括 10 项 Node 检查、WordPress 6.6.10、7.0.7、7.1.3 三组各 28 项 PHP 集成检查、74 个浏览器功能流程、4 组视觉测试和独立 ZIP 安装检查。三引擎测试不等同于所有实际设备或插件组合；本地资产大小变化不代表已测得生产环境 Core Web Vitals 提升。

详细计量口径、兼容说明与技术依据见[资源与视觉规范化](PERFORMANCE-AND-DESIGN.md)。
