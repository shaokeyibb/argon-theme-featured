# 3.0.1：布局与线上交互修复

3.0.0 将前端迁移到 Bootstrap 5 时，遗漏了部分 Argon Design System 的视觉参数。资源加载和一般交互测试没有覆盖真实站点升级前后的几何布局，导致导航、标题定位、行距与分页样式发生回归。3.0.1 在 Bootstrap 5 上显式保留这些设计参数，并补充真实页面对照与浏览器回归用例。

## 修复内容

- 恢复导航栏的顶部定位、尺寸、字体和透明背景渐变，保留后台指定的随滚动隐藏或绝对定位模式。
- 恢复 Banner 标题的定位容器，消除导航占位造成的正文下移，恢复装饰圆形的尺寸。
- 恢复 30px 栅格间距、标题行高、标签下边距、表单/按钮/弹窗等基础组件参数，以及圆形分页按钮。
- 保留普通 Markdown 图片的居中缩进，同时尊重带宽度的图片和 WordPress 原生图片区块。
- 顶部和侧栏搜索分别管理状态；恢复搜索输入框的定位容器，避免透明输入框覆盖分类菜单。
- 长说说和评论通过 ResizeObserver 在图片、字体加载和响应式布局变化后重新判断折叠，用户主动展开后保持展开。
- 首次公共 AJAX 请求前，通过禁止缓存的同源接口获取当前访客 nonce，避免缓存文章中的过期 nonce 导致验证码 403；会话中途过期时仅对明确的 nonce 失败重试一次。写操作原有 nonce、权限和所有权检查继续执行。
- 首页隐藏阅读进度。评论快捷按钮遵循主题选项，仅在存在评论区时显示；回到顶部按钮在滚动 400px 后显示。
- 评论框初始高度调整为 120px，并继续随内容自动增高；下方输入框统一为 48px 高、左右 14px 内边距。在手机上填写评论时隐藏浮动按钮，避免遮住发送按钮。
- 恢复目录随阅读位置展开当前分支、折叠其他分支的行为，修复当前标题高亮和根目录多余缩进。覆盖快速向上/向下滚动、目录链接跳转、深层标题以及带锚点刷新；实测时光轴的年份/月度目录。
- 恢复整套 Argon 配色：饱和底色提示框、浅色半透明徽章、按钮悬停/按下/禁用状态，以及后台 Banner 使用的渐变背景。修复评论“博主/置顶/悄悄话/待审核”徽章和历史文章短代码的颜色回归；补回夜间模式中提示链接的颜色优先级，保留自定义主题色。
- 核对评论点赞图标：日间使用主题色，夜间使用浅主题色，悬停和已点赞状态使用白色图标与主题色背景；恢复主题色描边。通过隔离 WordPress 实例验证实际点赞请求、计数和刷新后的状态，线上只做视觉检查。
- 恢复目录分支的 400ms 展开/收起、折叠块和评论额外输入框的 300ms 过渡、回复预览的展开/收起、编辑记录/通知/二维码的淡入淡出，以及说说点赞和评论加载按钮的反馈动画。导航下拉菜单恢复进入/退出过渡；侧栏、搜索、弹窗、卡片和图片灯箱继续使用现有动画。
- 展开动画在快速反向操作时从当前画面衔接，不排队；结束后恢复自然高度，适应换行和窗口尺寸变化。系统开启“减少动态效果”时立即切换。
- 分享按钮更新为微信二维码、微博、X、Telegram、WhatsApp、Facebook、Reddit、Bluesky、复制链接和系统分享，移除豆瓣、QQ、QQ 空间。保留后台国内/国外筛选；不支持系统分享的浏览器自动隐藏该按钮。分享地址直接由服务端生成，正确编码中文与特殊字符，外部平台链接在禁用 JavaScript 时仍可用。
- 修复缓存插件追加脚本查询参数后，懒加载模块反向导入页面入口导致的二次初始化。构建时将共享代码独立拆分，避免复制成功提示、二维码以及其他事件重复触发。

分享只打开各平台的编辑器，用户仍需登录并确认发送；主题不调用代发接口。二维码在本地生成，不向第三方二维码服务发送文章 URL。平台协议参考 [Telegram](https://core.telegram.org/widgets/share)、[WhatsApp](https://faq.whatsapp.com/5913398998672934)、[Bluesky](https://bsky.network/docs/intent-links/)、[X](https://help.x.com/en/using-x/add-x-share-button)；系统分享遵循 [Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)。自动测试覆盖跳转目标、参数与浏览器回退，不执行真实账号发帖。

## 页面对照

以升级前备份的公开首页/文章 HTML 与主题样式为基准，使用当前站点的相同内容、背景和配置，在桌面 1440×1000 和手机 390×844 下对比截图及计算样式。旧页面脚本被禁用，懒加载图片与初始导航状态由对照脚本恢复；该对照主要验证布局，交互另由真实浏览器测试验证。

| 桌面首页指标 | 升级前 | 3.0.0 | 3.0.1 |
| --- | ---: | ---: | ---: |
| Banner 顶部 Y | 0px | 75px | 0px |
| Banner 标题顶部 Y | 约 197px | 约 395px | 约 197px |
| 首张文章卡片顶部 Y | 443px | 518px | 443px |
| 导航栏高度 | 约 85.6px | 75px | 约 85.6px |
| 首页分页整体尺寸 | 375×66px | 约 326×68px | 375×66px |
| 统计标签下边距 | 8px | 0px | 8px |

Font Awesome 7 的字形和部分图标宽度仍与旧字体不同。正文容器继续使用 flow-root 包含浮动列，不恢复旧容器高度为零的布局缺陷。

颜色对照使用升级前实际部署的完整 CSS，覆盖 12 组组件色在日间/夜间的普通、悬停、按下、聚焦和禁用状态。除旧版中白底白字的 neutral/white 提示框改用深色文字外，配色保持一致；新旧 Sass 的 HSL 换算可能产生 1 个 RGB 色阶的舍入差异。英文版本提示恢复为 `#fc7c5f` 橙色背景与白色正文，“博主”徽章恢复为 `#2643e9` 文字与半透明 `#cbd2f6` 背景。
