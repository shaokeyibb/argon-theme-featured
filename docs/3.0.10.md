# 3.0.10：移动端滚动稳定性

修复 iPhone Chrome 在带图片的文章滑到底部后，向上滚动时页面与浏览器工具栏反复抖动的问题。

工具栏伸缩会改变 `innerHeight`。此前主题据此反复计算图片预览高度和折叠阈值，导致正文高度变化，与页面底部的滚动调整形成反馈循环。现在图片布局统一使用布局视口高度；工具栏伸缩未改变布局视口尺寸时，不再重排图片或中断展开动画。真正调整窗口尺寸或旋转设备时仍会重新布局。

新增回归重放真机采集的 681–780px 高度变化，并检查图片预览、折叠状态、页面高度、延迟加载后的计算与真实窗口缩放。真机对照中，单独暂停旧图片布局的窗口监听器即可恢复向上滚动。

修正两处浏览器回归的等待时序：原生灯箱完成焦点转移后再发送 Escape，长图收起后等待实际布局达到原高度上限，保留原有尺寸和关闭断言。

同时精简 README，集中展示主题能力、安装入口与文档导航。

WordPress / PHP 最低要求保持 6.6 / 8.2。升级时同步完整构建资源，并清理页面、静态资源及 CDN 缓存。
