# 3.0.6：正文宽度与叠图标题可读性

修复 3.0.5 外观规范化引入的正文宽度回归：正文位于纵向 Flex 卡片中时，自动水平外边距会让短文章和 HTML 文档收缩到内容固有宽度，HTML iframe 在桌面端可能只剩 300px。正文现在明确填满可用宽度，同时保留现有最大宽度约束和居中能力。

新增 Chromium、Firefox、WebKit 回归流程，分别检查短文章与 HTML 文档在桌面和手机宽度下填满卡片内容区域。该版本包含 3.0.5 的 Header 首屏、浏览器滚动恢复、现有配色规范化和资源优化。

同时将卡片入场动画对原生滚动恢复的保护扩展到页面刷新，避免带目录锚点的页面刷新后滚动位置偏移。

主页文章流和正文页的叠图标题改用更清晰的局部渐变遮罩、不透明白字与文字阴影。遮罩只覆盖图片下方的文字区域，分类等元数据链接随之使用浅色。没有特色图片、图文分栏的布局 2、图片与标题上下分离的布局 3，以及特色图片放入站点 Banner 的正文标题均不受影响。无需新增设置或外观预设。

已安装 3.0.5 的站点应升级到 3.0.6，并清理页面及样式缓存。WordPress 和 PHP 最低版本保持 6.6 / 8.2。
