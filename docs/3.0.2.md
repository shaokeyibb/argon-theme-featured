# 3.0.2：评论和说说折叠修复

真实站点在桌面与手机宽度间切换时，内容区域会短暂收窄到 0～20px，文字被排成很高的一列。旧逻辑只处理“从短变长”，一旦添加折叠状态就不再检查，因此一两行内容也可能一直显示展开按钮。

这次修复会等待宽度稳定后再判断，折叠后继续观察内部内容的自然尺寸。图片、字体、正文或布局变化使内容缩短时，自动撤销折叠与展开按钮。用户主动展开的内容继续保持展开。评论超过约 800px 时收起至 200px，说说超过约 400px 时收起至 400px，沿用原有阈值。

评论展开按钮原来放在 35px 高的容器里，但迁移后的按钮实际高度更高，导致底部被裁切。按钮现在统一为 32px 高、13px 字号，带向下箭头，评论按钮距裁切边缘保留 8px 空间；键盘焦点外框也能完整显示。
