# 3.0.8：暗色模式文字颜色修复

修复 Bootstrap 5 迁移后部分卡片继续使用浅色模式文字颜色的回归。此前普通文章正文有单独的暗色覆盖，说说、站点统计和文章 metadata 等区域仍显示深色文字，形成明显差异。

- 将 Bootstrap 正文、标题、强调和次级文字变量接入现有暗色配色，统一说说、小工具、metadata、评论、设置面板与弹窗的文字颜色。
- 修复小工具和归档标题的 `text-black` 固定深色覆盖暗色模式的问题。
- 同步表格、列表等组件的暗色背景和边框，避免浅色表面与浅色文字混用。
- 保留 metadata 原有透明度层级、浅色模式配色，以及作者在区块中显式指定的文字颜色。

新增 Chromium、Firefox、WebKit 回归测试，覆盖桌面与移动端、普通暗色、沉浸色、纯黑模式和切回浅色。WordPress 和 PHP 最低版本保持 6.6 / 8.2。升级后请清理页面、静态资源和 CDN 缓存。
