# 3.0.12：恢复导航栏配色和悬停效果

修复 Bootstrap 5 重构后，夜间模式导航栏文字被通用链接样式覆盖、显示为主题色的问题。

- 对照重构前 `e789d48` 的实际构建产物，恢复桌面端原有配色：Logo 和一级菜单默认使用 95% 白色；Logo 在 hover / focus 时变为纯白，菜单变为 65% 白色，明暗模式一致。
- 恢复菜单激活、展开和禁用状态的原有颜色，以及手机展开菜单日间的深色文字，保留夜间的浅色文字。
- 补回导航颜色声明所需的选择器优先级，避免再次被夜间通用链接规则覆盖。

验证：36 项新旧构建可见文字颜色对照一致；Chromium / Firefox 共 22 项 Header 测试通过，10 项资源检查通过，完成 4 项视觉检查并更新两张夜间 Header 基线。当前本地环境缺少 WebKit 所需系统库，该引擎未能启动。

WordPress / PHP 最低要求保持 6.6 / 8.2。升级时同步完整构建资源，并清理页面与静态资源缓存。
