# 3.0.9：图片排版与长图预览

改善正文、说说及折叠块中的图片阅读体验，解决大幅竖图占满页面、连续照片留白过多、带图注图片偏移和嵌套容器漏掉排版规则的问题。

- 相邻的纯图片段落与带图注图片自动组成最多两列的瀑布流，按可用容器宽度切换列数，保留全部图片及原始顺序。
- 桌面图片区域统一居中并限制宽度，窄屏使用可用宽度；预计完整显示高度超过视口高度的 75% 时，提供 60% 视口高度的顶部预览。
- 长图展开、收起使用约 300ms 动画，图注、相邻图片和后续正文同步移动；快速反向操作从当前尺寸继续，尊重系统的减少动态效果偏好。切换期间避免浏览器自动滚动锚定，让图片从底部向下展开。
- 完整显示普通 figure 与经典图注，包括长文本和连续链接；将图注实际高度计入排版，避免重叠、截断或省略。
- 折叠块、提示框、列表、原生 details 和其他嵌套正文容器分别组织自己的图片流；隐藏容器重新打开、延迟图片加载及窗口变化后重新测量，不跨容器移动图片。
- 保留原有 picture/source、响应式图片属性、替代文本、链接和灯箱顺序；作者指定的尺寸、原生图片/图库区块、表格及显式排除的内容继续使用自己的布局。展示增强不改写文章或附件数据。

新增 Chromium、Firefox、WebKit 专项回归，覆盖嵌套容器、图注、长图动画、滚动位置、快速切换、响应式布局、打印和减少动态效果，并使用实际文章验证桌面与手机排版。WordPress 和 PHP 最低版本保持 6.6 / 8.2。升级后请清理页面、静态资源和 CDN 缓存。
