# Argon-Theme-Featured

基于 Argon-Theme V2 的继承版本

## 特性

- AI 文章摘要
- WP Statistics 阅读量支持
- Discourse 内嵌评论区集成
- 更多...

## 安装

### 安装最新分支版本
您需要先安装 php 和 composer，并在本仓库目录下运行 `composer install`，随后便可将整个仓库打包作为主题安装到您的 WordPress 中。

### 安装 Release 版本
前往 [Latest Release](https://github.com/shaokeyibb/argon-theme-featured/releases) 页面下载 .zip 文件，在 WordPress 后台 "主题" 页面上传并安装。
